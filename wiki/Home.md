# API Signals Wiki

**API Signals** is an open-source, offline-first HTTP client for **macOS** and **Windows**, built with Tauri (React + Rust).

## Stack

| Layer | Technology |
| --- | --- |
| UI | React 18, TypeScript, Vite, Tailwind |
| Shell | Tauri 2 |
| Backend | Rust, rusqlite, reqwest |
| Data | SQLite (local app data directory) |
