# Contributing

Full guide: [docs/CONTRIBUTING.md](https://github.com/apisignals/api-signals/blob/main/docs/CONTRIBUTING.md).

1. Fork and branch from `main`.
2. `cd tauri && npm ci && npm run tauri dev`
3. Run `npm test` and `cargo test` in `tauri/src-tauri`.
4. Open a PR with a clear description.

Code of conduct: [CODE_OF_CONDUCT.md](https://github.com/apisignals/api-signals/blob/main/CODE_OF_CONDUCT.md).
