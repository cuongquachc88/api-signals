Capabilities

Everything you reach for daily

Request editing, response inspection, collections, and imports — tuned for speed on Apple silicon.

  • GET Full URL bar Query params stay in sync with the address bar — edit either side.
  • JSON Folding editor Line numbers, collapse chevrons, beautify, minify, live validation.
  • cURL Paste to import Drop a multiline curl into the URL field; headers, auth, and body fill in.
  • AUTH Bearer to OAuth Basic, API key, OAuth 2.0, and more — applied when the request leaves.
  • SYNC Offline workspaces Collections, environments, history in GRDB. Export Postman, OpenAPI, HAR.
  • LIVE WebSocket & SSE Watch streams beside classic request/response workflows.

Get started

Build in a minute

macOS 14+ and a Swift 6 toolchain. Clone, build, codesign, open.

# from repo root
cd macOS
swift build -c release
cp -f .build/release/APISignalsApp APISignals.app/Contents/MacOS/APISignals
codesign --force --deep --sign - APISignals.app
open -n APISignals.app
